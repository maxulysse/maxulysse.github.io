I made [nf-arts](https://maxulysse.github.io/nf-arts/), a Nextflow plugin that turns each run into generative art. When the run ends, it draws its tasks as an SVG or PNG from their timing, memory and status only.

Add `id 'nf-arts@1.1.0'` to the `plugins` block of your `nextflow.config` to try it, and see the [gallery](https://github.com/maxulysse/nf-arts/blob/main/docs/gallery.md) for the different styles.
