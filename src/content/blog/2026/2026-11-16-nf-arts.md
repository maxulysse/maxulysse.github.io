I made [nf-arts](https://github.com/maxulysse/nf-arts), a Nextflow plugin that turns each run into generative art. When the run ends, it draws its tasks as an SVG or PNG from their timing, memory and status only.

[<img src="/assets/img/posts/2026/nf-arts-ginkgo.png" title="nf-arts ginkgo style" alt="A test run of nf-core/rnavar drawn by nf-arts in the ginkgo style" width="600">](https://maxulysse.github.io/nf-arts/1.1.0/styles/)

Add `id 'nf-arts@1.1.0'` to the `plugins` block of your `nextflow.config` to try it, and see the [docs](https://maxulysse.github.io/nf-arts/) for the configuration and all the styles.
